C Mini ProjectProject: 
Password-Protected Note Encryption Tool (C-based CLI)
1. Objective
The goal of this project is to build a command-line tool in C that encrypts and decrypts plaintext files using a simple XOR-based password encryption scheme. The tool should allowusers to convert sensitive text notes into unreadable formats and retrieve the original contentwhen needed, using a password.
2. Project Scope
This tool simulates basic encryption and decryption using a symmetric key (same passwordfor encryption and decryption). It reinforces fundamental concepts of:

╬ô├ç├│ Input validation and simple user interactions
3. Features

5. How does it work?
Encryption 
Flow:
1. User runs:./<executable_file> -e <.txt file to be encrypted> <output encryptedfile_name.enc>2. Program prompts for password (e.g., abc123)
3. Validate the password4. It reads characters from input.txt5. Each character is XOR╬ô├ç├ûd with the first character of the password6. Output is written to an encrypted.enc
Decryption 
Flow:
1. User runs:./<executable_file> -d <input decrypted file_name.enc> <.txt file to bedecrypted>
2. The program asks for the same password
3. Validate the password.
4. It reads characters from the encrypted file
5. Each character is XOR╬ô├ç├ûd again with the same key6. Output is written to output.txt (original message is recovered)
